# Особенности
* Переведен весь текст ивентов, меню и скриптов (визуальная часть осталась на английском)
* Обновлены шрифты для корректного отображения текста в игре
* Убрана возможность менять шрифт в меню т.к это ломает отображение кириллицы
* Релиз оформлен как перевод внутри движка, замена файлов осуществляется только для шрифтов
* -Небольшой подарок во внутриигровом компьютере ГГ-

_**!!! Большая часть текста была переведена при помощи ИИ, но текст был отредактирован вручную !!!**_

# Установка
1. Скачайте последний [релиз](https://github.com/vodichkafiji/AfterDark-Rus/releases)
2. Распакуйте архив
3. Перенесите папку в корень игры (с заменой файлов)
4. Готово!
